# 六类基础金标准回归包

`golden-cases-v0.8.0.json` 锁定 v0.8.0 六类基础代表算例的类型、入口测试、关键数值和容差。

该包用于发现程序改动造成的数值漂移。圆形刚性短柱桩保留原 Excel 证据链，但 Excel 只作为历史数值证据；其公式仍须按现行规范独立核对。其余案例是项目内回归基线，不宣称已经获得第三方审图、试验或权威软件比对。正式使用前仍应逐步补齐至少一套经审查计算书或试验结果作为外部金标准。

验收规则：

1. 六种 `FoundationType` 必须各出现一次，`caseId` 不得重复。
2. 所有 `runnerTestName` 必须在自动测试清单中实际执行并通过。
3. 锁定指标不得静默更新；确需更新时必须同步修改版本号、原因和复核记录。
4. 自动验收生成 `output/validation/golden-benchmark-v0.8.0.md`，明确区分“程序回归通过”和“外部权威验证完成”。
