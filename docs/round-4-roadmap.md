# 塔基智设第四轮实施建议

建议第四轮把“已有计算能力”提升为“可审查、可交付、可维护”的工程产品，按以下顺序实施。

## 1. 外部金标准与双人复核闭环（最高优先级）

- 为六类基础各收集不少于3个经审查计算书、试验或权威软件结果，覆盖通过、临界和不通过工况。
- 将现有项目内回归基线升级为外部金标准，逐项锁定输入、公式版本、期望值、容差和复核人。
- 建立“差异解释”报告；任何核心公式或规范版本变化都必须经过双人确认才能更新基线。

## 2. 地勘数据结构升级

- 从单一参数表升级为钻孔、层底标高、层厚、地下水时序、持力层和特殊土结论的结构化模型。
- AI只做候选提取；页码、表号、钻孔号和原文证据必须同时入库。
- 增加同场地多钻孔差异提示、基础位置附近代表性钻孔人工选择，以及超出勘探范围的明确门禁。

## 3. 正式施工图模板体系

- 建立企业A3/A2图框、图层、线型、字体、比例、图号和会签栏模板。
- 分六类基础补齐平面、剖面、节点索引、钢筋编号、锚固/搭接、保护层、施工说明和试桩/检测说明。
- 开发本地CAD插件或受控命令行转换，把DXF稳定生成DWG并进行图层、文字和尺寸复核；当前SCR继续作为兼容路径。

## 4. 锚栓与塔脚节点专项模块

- 在取得明确采用的规范/企业节点方法后，完成群锚、开裂混凝土、边距/间距、构件厚度、附加钢筋和底板连接模型。
- 将“公式来源、适用条件、单位体系和系数”做成可版本化规则包，禁止跨项目静默复用。
- 增加厂家节点详图与计算结果的一致性校核，并输出节点专项计算书。

## 5. 桩基与特殊地基深化

- 用试桩和经审查算例校准分层Mindlin/等代实体沉降模型，加入群桩效应、桩端刺入和长期固结边界。
- 完成负摩阻中性点、荷载传递与特殊地基处理后的复核路径。
- 湿陷、液化、冻胀、填土和腐蚀性条件继续采用专项规则包，不以一个默认数字结束风险。

## 6. 审批、变更与发布治理

- 为项目增加设计、校核、审定三角色签署及只读归档快照，计算书、CAD、材料表共享同一哈希和版本号。
- 增加参数变更对比、重新计算影响范围和作废成果标记，避免旧图与新计算书混用。
- 形成带签名清单的离线安装包、崩溃日志和可回退升级机制；密钥、项目和企业库继续与程序发布包分离。
